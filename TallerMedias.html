2 PARTE I. Datos no agrupados

2.1 Ejercicio 1. Tiempos de respuesta a solicitudes

Fórmula (media aritmética):

\bar{x} = \frac{\sum_{i=1}^{n} x_i}{n}

donde x_i es el tiempo de respuesta (días hábiles) de la solicitud i y n = 12.

Ver código 
# 1. Datos
dias <- c(3, 5, 4, 6, 8, 4, 7, 5, 3, 9, 6, 4)

# 2. Media con mean()
media_dias <- mean(dias)

# 3. Cálculo manual y comprobación
media_manual <- sum(dias) / length(dias)

round(media_dias, 4)
[1] 5.3333
Ver código 
round(media_manual, 4)
[1] 5.3333
Ver código 
all.equal(media_dias, media_manual)
[1] TRUE
Ver código 
# 4. Comparación con la meta de 5 días hábiles
meta <- 5
media_dias <= meta
[1] FALSE

Meta institucional (actividad 4). El tiempo promedio es 5.33 días hábiles, es decir, 0.33 días por encima de la meta de 5. No se cumple la meta en promedio. Además, 7 de las 12 solicitudes (el 58,3 %) se resolvieron en 5 días o menos, pero las solicitudes de 7, 8 y 9 días elevan el promedio.

Pertinencia de la media aritmética (actividad 5). Los tiempos son valores aditivos medidos en la misma unidad (días), y cada solicitud tiene el mismo peso. La suma de los tiempos tiene sentido (días totales de trabajo) y el promedio indica cuánto tarda, en promedio, una solicitud. Por eso la media aritmética es la medida adecuada. Su limitación es la sensibilidad a valores extremos, como el de 9 días.

2.2 Ejercicio 2. Velocidad de atención de brigadas

Fórmula (media armónica):

H = \frac{n}{\sum_{i=1}^{n} \frac{1}{x_i}}

Condición: ningún x_i puede ser cero (y deben ser positivos).

Ver código 
# 6. Vector de velocidades (km/h)
velocidad <- c(24, 30, 36, 40, 45)
stopifnot(all(velocidad > 0))   # verificación de condición

# 7. Media armónica manual
H_manual <- length(velocidad) / sum(1 / velocidad)

# 8. Verificación con paquetes
H_psych <- psych::harmonic.mean(velocidad)
H_desc  <- DescTools::Hmean(velocidad)

# 9. Comparación con la media aritmética
media_vel <- mean(velocidad)

resultados2 <- data.frame(
  Medida = c("Armónica (manual)", "Armónica (psych)",
             "Armónica (DescTools)", "Aritmética"),
  `Velocidad (km/h)` = round(c(H_manual, H_psych, H_desc, media_vel), 4),
  check.names = FALSE
)
kable(resultados2)
Medida Velocidad (km/h)
Armónica (manual) 33.3333
Armónica (psych) 33.3333
Armónica (DescTools) 33.3333
Aritmética 35.0000

Interpretación (actividad 10). Con recorridos de igual longitud d, el tiempo total es \sum d/x_i y la distancia total es n \cdot d. La velocidad promedio real es distancia total / tiempo total = n / \sum (1/x_i), que es exactamente la media armónica (33.33 km/h). La media aritmética (35 km/h) sobrestima la velocidad promedio porque da el mismo peso a cada velocidad, cuando las brigadas lentas pasan más tiempo en carretera. Se cumple siempre que H \le G \le \bar{x}.

Si las distancias fueran diferentes, ya no se usaría la media armónica simple, sino la armónica ponderada por distancias: H = \sum d_i / \sum (d_i/x_i). Si en cambio los tiempos fueran iguales, la media correcta sería la aritmética.

2.3 Ejercicio 3. Crecimiento de la recaudación municipal

Fórmula (media geométrica de factores):

G = \left(\prod_{i=1}^{n} f_i\right)^{1/n} = \exp\left(\frac{1}{n}\sum \ln f_i\right), \qquad f_i = 1 + \frac{r_i}{100}

\text{tasa compuesta} = (G - 1)\times 100

Ver código 
# 11. Tasas porcentuales
tasas <- c(6, 9, 12, 5, 10)

# 12. Factores de crecimiento
factores <- 1 + tasas / 100
stopifnot(all(factores > 0))

# 13. Media geométrica y tasa compuesta
G <- exp(mean(log(factores)))
tasa_compuesta <- (G - 1) * 100

round(G, 6)
[1] 1.083694
Ver código 
round(tasa_compuesta, 4)
[1] 8.3694
Ver código 
# 14. Comparación con la media aritmética simple
round(mean(tasas), 4)
[1] 8.4
Ver código 
# 15. Verificación con paquetes
G_psych <- psych::geometric.mean(factores)
G_desc  <- DescTools::Gmean(factores)
c(manual = G, psych = G_psych, DescTools = G_desc) |> round(6)
   manual     psych DescTools 
 1.083694  1.083694  1.083694
Ver código 
c(manual = tasa_compuesta,
  psych = (G_psych - 1) * 100,
  DescTools = (G_desc - 1) * 100) |> round(4)
   manual     psych DescTools 
   8.3694    8.3694    8.3694

Interpretación (actividad 14). La tasa anual compuesta promedio es 8.37 %, ligeramente inferior a la media aritmética de las tasas (8.4 %). Difieren porque el crecimiento se acumula multiplicativamente: cada año crece sobre la base del año anterior. La media geométrica es la tasa constante que, aplicada durante cinco años, produce el mismo crecimiento total que las tasas observadas. La media aritmética siempre es mayor o igual que la geométrica, y la diferencia crece con la dispersión de las tasas.

Medida Expedientes/hora
Armónica ponderada 5.9259
Aritmética ponderada 6.6000

Discusión (actividad 25). La armónica ponderada (5.93) es menor que la aritmética (6.6). Cuál es defendible depende de qué se mantiene constante:

  • La media armónica es la correcta cuando cada tasa se observa sobre la misma cantidad de trabajo (el mismo número de expedientes, es decir, igual “numerador”). Entonces el tiempo total es \sum (\text{expedientes}/x_i) y la tasa global real es expedientes totales / tiempo total.
  • La media aritmética es la correcta cuando cada tasa se observa durante el mismo tiempo (jornadas de igual duración), pues los expedientes totales son \sum x_i \cdot t.

Aquí las frecuencias cuentan jornadas. Si todas las jornadas tienen igual duración, el promedio de tasas apropiado sería el aritmético (6.6), y la armónica subestimaría el rendimiento. La armónica sería defendible solo si cada grupo de jornadas hubiera procesado un volumen igual de expedientes, algo que el enunciado no indica. En conclusión: para interpretar la armónica como promedio de tasas debe garantizarse una exposición equivalente en cantidad de trabajo entre los grupos.

3.3 Ejercicio 6. Factores de crecimiento de la cobertura

Fórmula (media geométrica ponderada):

G = \exp\left(\frac{\sum f_i \ln x_i}{\sum f_i}\right)

Ver código 
# 26. Vectores
xi <- c(1.02, 1.05, 1.08, 1.12)
fi <- c(4, 8, 5, 3)
stopifnot(all(xi > 0))

# 27. Media geométrica ponderada
G <- exp(sum(fi * log(xi)) / sum(fi))
round(G, 6)
[1] 1.061535
Ver código 
# 28. Tasa porcentual
tasa <- (G - 1) * 100
round(tasa, 4)
[1] 6.1535
Ver código 
# 29. Verificación con datos expandidos
datos <- rep(xi, times = fi)
round(DescTools::Gmean(datos), 6)
[1] 1.061535
Ver código 
round(psych::geometric.mean(datos), 6)
[1] 1.061535
Ver código 
# Referencia: media aritmética ponderada de los factores
round(sum(fi * xi) / sum(fi), 6)
[1] 1.062

Interpretación (actividad 30). El factor de crecimiento promedio es 1.0615, equivalente a un crecimiento anual típico de la cobertura de 6.15 %. Los factores se multiplican de un periodo a otro (la cobertura final es la inicial por el producto de los factores), por eso el promedio adecuado es la media geométrica: es el factor constante que reproduce el mismo efecto acumulado. Promediar aritméticamente los factores sobrestimaría ligeramente el crecimiento.

41–42. Elección y justificación. Ver la tabla anterior.

43. Por qué no una única medida. Cada media responde a una estructura distinta del fenómeno: suma de cantidades (aritmética), razones con numerador constante (armónica) y productos de cambios relativos (geométrica). Aplicar la misma a todos produce sesgos: la aritmética sobrestima velocidades promedio y tasas compuestas; la armónica y la geométrica no tienen sentido para tiempos simples. Además existe la relación H \le G \le \bar{x}, de modo que elegir mal sistemáticamente desplaza el resultado.

44. Indicadores adicionales propuestos.

  • Aritmética: monto promedio de recaudación de impuesto predial por predio, o número promedio de personas atendidas por ventanilla por día.
  • Armónica: rendimiento promedio (km por galón) de vehículos de inspección que recorren la misma ruta, o costo por beneficiario cuando se gasta un mismo presupuesto en distintos programas.
  • Geométrica: crecimiento anual compuesto del presupuesto de inversión, o variación anual de la matrícula en programas sociales.

5.2 Ejercicio 10. Informe breve de resultados

5.2.1 Objetivo y contexto

La Secretaría de Hacienda de un municipio requiere conocer la tasa anual compuesta promedio de crecimiento de la recaudación propia en los últimos cinco años, para proyectar ingresos y compararla con el resultado de otras entidades. Se dispone de las tasas anuales de crecimiento: 6 %, 9 %, 12 %, 5 % y 10 % (datos simulados).

5.2.2 Medida, fórmula y justificación

Se calculó la media geométrica de los factores de crecimiento f_i = 1 + r_i/100:

G = \left(\prod f_i\right)^{1/n}, \qquad \text{tasa compuesta} = (G-1)\times 100

La recaudación de cada año crece sobre la del año anterior, por lo que el efecto acumulado es un producto de factores; la media geométrica es la que conserva ese efecto acumulado.

5.2.3 Código y resultado

Ver código 
tasas <- c(6, 9, 12, 5, 10)
factores <- 1 + tasas / 100
G <- exp(mean(log(factores)))
tasa_compuesta <- (G - 1) * 100

resultado10 <- data.frame(
  Medida = c("Media geométrica de factores", "Tasa anual compuesta (%)",
             "Media aritmética de tasas (%)",
             "Crecimiento acumulado del periodo (%)"),
  Valor = round(c(G, tasa_compuesta, mean(tasas),
                  (prod(factores) - 1) * 100), 4)
)
kable(resultado10)
Medida Valor
Media geométrica de factores 1.0837
Tasa anual compuesta (%) 8.3694
Media aritmética de tasas (%) 8.4000
Crecimiento acumulado del periodo (%) 49.4625
Ver código 
# Comprobación: aplicar G cinco veces equivale al crecimiento acumulado
all.equal(G^5, prod(factores))
[1] TRUE

5.2.4 Interpretación en lenguaje de gestión pública

La recaudación propia creció, en promedio, 8.37 % anual compuesto durante el periodo. Esto equivale a un incremento acumulado de 49.5 % en cinco años. Si la administración hubiera usado la media aritmética (8.4 %), habría sobrestimado levemente el ritmo de crecimiento y, por tanto, los ingresos proyectados.

5.2.5 Limitación y condición de uso

La media geométrica exige que todos los factores sean positivos y asume que el crecimiento se compone año a año sobre la base anterior. Es un promedio de un periodo corto (cinco observaciones) y no garantiza que el crecimiento futuro se mantenga: no refleja la volatilidad ni cambios normativos o de la base tributaria.
